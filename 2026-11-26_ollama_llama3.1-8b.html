[PATCH v2] eth: bnxt: fix the agg page pool recycle ring size Neutral llm-chunked-no-replies Awaiting Review

This patch fixes a bug in the aggregation (agg) page pool recycle ring size calculation for the Broadcom NIC driver (bnxt). The issue was caused by an incorrect divisor used to calculate the fill level of the agg queues, leading to an under-sized recycle ring. The fix divides the fill level by the number of buffers per allocation, using the maximum of the page size and rx_page_size as the divisor. This change ensures that the recycle ring is properly sized for different kernel configurations and buffer sizes, preventing memory leaks in certain scenarios.

Ongoing Submitted 2026-11-25 🔥 TODAY [PATCH] eth: bnxt: fix the agg page pool ring size on 64K-page kernels Needs Work LLM (per-reviewer) Under Review

This patch fixes an issue in the Broadcom bnxt driver where the aggregate (agg) page pool ring size is incorrectly calculated on 64K-page kernels. The problem arises because the divisor used to calculate the ring size is always 1 when rx_page_size is 32K, leading to a cache that can hold twice as many pages as the agg ring uses. This causes memory waste and can lead to issues like reduced cached memory. To fix this, the patch changes the divisor to be the larger of PAGE_SIZE and rx_page_size, restoring the original size calculation.
