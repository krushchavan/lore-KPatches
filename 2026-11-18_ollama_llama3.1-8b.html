This patch introduces the concept of 'common memory' as a separate entity from NUMA nodes that have memory, allowing for private node memory to be isolated from the main memory management system. The patch creates a new flag N_MEMORY_COMMON and converts existing users of N_MEMORY to use this new flag instead. This is the first phase of a series that aims to introduce private NUMA nodes and allow userland to manage them via mbind() and migrate_pages().

Show 3 individual patches
  • [1/3] mm: page_alloc: add a watermark check that knows the migratetype Submitted 2026-11-16
  • [2/3] mm: page_alloc: make the high-order watermark check honour ALLOC_NOFRAGMENT 🔥 TODAYNeutralUnder Review Submitted 2026-11-16 Dev Jain
  • [3/3] mm: vmscan: tell direct reclaim the allocation is ALLOC_NOFRAGMENT Submitted 2026-11-16
Needs Work LLM (per-reviewer) Under Review

This patch series addresses a performance issue caused by the high-order watermark check not honouring the ALLOC_NOFRAGMENT flag in memory pressure situations. The check currently counts free pages of every migratetype, leading to incorrect results and stalls in compaction. The patches modify the watermark checks to take into account the request's migratetype and skip free lists that cannot be used. This is achieved by passing the alloc_flags to try_to_free_pages() and modifying the should_reclaim_retry() function. The changes are based on a benchmark that shows significant improvements in performance, with 64K mTHP faults under memory pressure stalling 18 times less often than without the patch series.
