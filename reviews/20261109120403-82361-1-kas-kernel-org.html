[PATCH v2 0/2] mm/memory: refuse to map page cache folios that are not uptodate

Active on: 2026-11-09
Patch summary
This patch series addresses a problem where page cache folios that are not up-to-date can be mapped, leading to stale memory being leaked to userspace. The patches add a backstop to refuse mapping such folios in the __do_fault() and do_set_pmd() functions. Patch 1 fixes a race condition that would trip over this backstop by rechecking PG_uptodate after ->page_mkwrite().
