View on lore.kernel.org →
Submitted: 2026-10-30
Active on: 2026-10-30
Patch summary
This patch series adds new export options to the NFS server (nfsd) for controlling read and write I/O modes on a per-export basis, replacing global debugfs switches. The options are read_io= and write_io=, which can be set to buffered, direct, or dontcache. This change aims to provide more fine-grained control over I/O behavior and eventually move these controls to something more permanent.
