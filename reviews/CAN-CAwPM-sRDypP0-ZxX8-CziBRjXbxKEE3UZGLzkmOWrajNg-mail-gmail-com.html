Patch summary
This patch prevents tiering promotions from being fed into task placement statistics in the Linux kernel's NUMA (Non-Uniform Memory Access) balancing code. This fix addresses incorrect NUMA balancing behavior that could be visible to userspace, specifically regarding task placement and related accounting. The patch is considered a fix rather than an optimization, and it is recommended to submit it independently with a Fixes: tag and cc:stable.
