Patch summary
This patch separates the scanning of a PTE table from collapsing it into two distinct functions: collapse_scan_pmd() and collapse_run_pmd(). The scan function reads the PTE table under mmap_lock to determine if the range is worth collapsing, while the run function performs the actual collapse. This change improves code organization and allows for better tracing and reporting of collapse operations.

Kiryl Shutsemau (author) 2026-09-07 Neutral LLM
Author addressed Zi Yan's concern about the scan_retract_only flag being set to true in collapse_scan_pmd, explaining that this is a necessary optimization for when the PMD folio is already in the page cache and only the PTE table needs to be retracted. The author plans to fold these changes into v2.
