Patch summary
This patch series addresses various issues in the NFSv4 server's delegated timestamp support, including bugs and inconsistencies in how timestamps are updated and handled. The patches aim to improve the accuracy and reliability of timestamp updates, particularly in scenarios involving file copying, cloning, and delegation.

nfsd_break_deleg_cb() can run more than once per lease:
- __break_lease() calls lm_break for a read breaker
  (FL_DOWNGRADE_PENDING) and again for a later write breaker
  (FL_UNLOCK_PENDING);
- nfsd_handle_dir_event() and nfsd_recall_all_dir_delegs() call it
  directly, possibly repeatedly.

Each call incremented cl_delegs_in_recall, but nfsd_change_deleg_cb()
decrements it once at F_UNLCK. The leaked count keeps
nfs4_anylock_blockers() true, so the client can never again become a
courtesy client.

Skip setting dl_recalled, the increment, the client expiry, and
fi_had_conflict when dl_recalled is already set. All callers and the
F_UNLCK decrement run under flc_lock. fl_break_time = 0,
nfsd_break_one_deleg() and the false return stay unconditional.

Show original comment 
nfs4_open_delegation() refuses delegations for NFSv4.0 write opens on
CLAIM_NULL and CLAIM_FH, as its comment explains, but CLAIM_PREVIOUS
skips the check. An NFSv4.0 client reclaiming a write open during grace
can therefore get a write delegation, and a GETATTR it sends before
DELEGRETURN in the same compound can never be answered.

Apply the same check to CLAIM_PREVIOUS.

Addressed a bug where the NFSv4 server was granting read delegations with attributes when timestamps were requested, leading to incorrect behavior. Changed the delegation type to OPEN_DELEGATE_READ instead.
Show original comment 
__nfsd_setattr() adds ATTR_CTIME only when ATTR_DELEG is clear, to keep a
delegated atime-only update from moving ctime. But ATTR_DELEG is set for
the whole iattr, so a holder's chmod or chown sent along with a delegated
atime changes the mode or owner without updating ctime.

Add ATTR_CTIME unless the request is a delegated atime-only update. A
delegated mtime whose ctime failed vetting now gets ctime = now instead
of no ctime update.

Fixes: f9a348e0de19 ("nfsd: don't set the ctime on delegated atime updates")
