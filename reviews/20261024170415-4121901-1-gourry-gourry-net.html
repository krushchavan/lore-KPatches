Patch summary
This patch updates the automatic interleave weights in Linux's memory policy when a node gains or loses memory due to hotplug events. The current implementation only recalculates the weights when a new bandwidth is reported, which can lead to incorrect weights being used for some nodes. This patch introduces a new function `wi_state_refresh` that recomputes the weights from the recorded bandwidth whenever a node gains its first memory or loses its last. This ensures that the weighted interleave algorithm always uses accurate and up-to-date weights, leading to improved performance in certain scenarios.
