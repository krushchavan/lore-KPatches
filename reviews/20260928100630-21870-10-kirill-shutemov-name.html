Patch summary
This patch separates the scanning of a PTE table from collapsing it into two distinct functions: collapse_scan_pmd() and collapse_run_pmd(). The scan function determines whether a range is worth collapsing, while the run function performs the actual collapse. This change improves performance by reducing the number of times the mmap_lock is dropped and taken, and also simplifies the code by breaking down complex operations into smaller, more manageable pieces.
