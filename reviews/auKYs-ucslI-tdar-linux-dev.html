Patch summary
This patch series addresses an issue where the mod_memcg_state() function is called multiple times for each socket, leading to inefficiencies. The patches batch these calls together, reducing overhead and improving performance. The changes are targeted at MEMCG_SOCK, correcting a typo in the original code.
