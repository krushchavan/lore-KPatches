Patch summary
This patch renames the bitmap 'mthp_present_ptes' to 'eligible_ptes' in the mm/khugepaged code, as its name no longer accurately reflects what a set bit means. A set bit indicates that a PTE has passed various checks and can be considered for collapse. The change is made to improve clarity and accuracy of the code, but does not introduce any functional changes.
