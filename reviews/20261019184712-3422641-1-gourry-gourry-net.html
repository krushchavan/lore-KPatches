[PATCH] mm/memory-tiers: reset demotion targets of nodes without memory

View on lore.kernel.org →
Submitted: 2026-10-19
Active on: 2026-10-19
Patch summary
This patch resets the demotion targets of nodes without memory to prevent stale entries from being used by reclaimers. The current implementation only resets nodes that have N_MEMORY set, which can lead to incorrect demotion targets when a node regains its last memory block and rebuilds its targets.
Gregory Price (Meta) 2026-10-19 Neutral LLM
Clarified the timing of node state changes and acknowledged that for_each_node() is necessary to handle these cases.
