Patch summary
This patch adds a new structure called `struct btrfs_eb_prealloc` to carry extent_buffer and btrfs_folio_state for NOFAIL allocations with retries outside the critical section. The existing allocation pathways are refactored to use this new structure without any functional changes. Empty prealloc structs are wired in from callers, and several files have been modified as a result.
