Patch summary
This patch adds self-tests to exercise the MADV_COLD and MADV_PAGEOUT functionality in the Linux kernel. The tests cover both user-visible contracts, such as verifying that MADV_COLD does not populate PTE holes and that PAGEOUT preserves unevictable base pages, as well as implementation details like folio and page-table behavior under various scenarios. The patch includes 28 cases to test these behaviors, with some tests intentionally asserting specific conditions to detect unintended changes during a planned refactor of the page-table walker.
