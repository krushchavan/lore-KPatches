[PATCH RFC] mm/gup: batch contiguous pages in follow_page_mask() and return them via a pages array

View on lore.kernel.org →
Submitted: 2026-07-31
Active on: 2026-07-31
Patch summary
This patch optimizes the way Linux handles page table walks by batching contiguous pages in the follow_page_mask() function and returning them via a pages array. This reduces the number of repeated page table walks, especially for PTE-mapped large folios, which can lead to significant performance improvements. The patch also simplifies the code by removing unnecessary loops and refactoring the logic to avoid restarting the walk at every folio boundary. Additionally, it fixes a silent correction in the old page_increm clamp, making it more robust and reliable.

I've split up the patch into a series of 5 now:
1) mm/gup: convert follow_page_mask() to return a long
2) mm/gup: split follow_page_pte_commit() out of follow_page_pte()
3) mm/gup: add gup_fill_pages() and use it
4) mm/gup: return a huge page's full count from follow_page_mask()
5) mm/gup: walk multiple PTEs per follow_page_pte() call

The changelogs naturally got shorter with things
split up this way.
