[PATCH 44/60] mm: add N_MEMORY_COMPACTION node state

View on lore.kernel.org →
Submitted: 2026-11-20
Active on: 2026-11-20
Patch summary
This patch adds a new internal node state called N_MEMORY_COMPACTION to the Linux kernel. This state indicates that the kernel can compact memory on its own initiative for the given node. The patch also updates various files, including documentation and code, to reflect this new state. The addition of this state allows the kernel to more efficiently manage memory compaction across different nodes in the system.
Gregory Relay 2026-11-20 Reviewed-by Neutral LLM
Reviewer noted that the addition of N_MEMORY_COMPACTION to enum node_states requires updating the BUILD_BUG_ON checks in drivers/base/node.c and include/linux/nodemask.h, as well as adding a new bit to NODE_MEMORY_FEAT_ALL.

From: "Gregory Price (Meta)" <gourry@gourry.net>

Add N_MEMORY_COMPACTION for the nodes compaction may operate on, and
NODE_MEMORY_FEAT_COMPACTION for memory providers to select it.

Common memory carries every feature, so a mask with
NODE_MEMORY_FEAT_COMMON must now include compaction.

The state is internal and has no sysfs file. Internal states follow
N_GENERIC_INITIATOR, so check sysfs coverage only for the states up to
it.
