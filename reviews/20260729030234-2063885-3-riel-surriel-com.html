Patch summary
This patch optimizes the handling of PTE-mapped large folios in the Linux kernel's memory management system. Currently, follow_page_mask() returns one page per call for a PTE-mapped large folio, leading to inefficient re-walking of page tables. The patch introduces a new function, folio_pte_batch_flags(), which counts consecutive present PTEs mapping contiguous pages with uniform write bits. This allows the kernel to batch contiguous runs of pages in one step, improving performance for large anonymous regions. The patch also maintains per-PTE guarantees and ensures that writable runs are safe for any access, while read-only runs are only batched for plain reads.
