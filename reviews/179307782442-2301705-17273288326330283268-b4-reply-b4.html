[PATCH 25/46] mm/userfaultfd: wake waiters when registration modes are removed

View on lore.kernel.org →
Submitted: 2026-10-27
Active on: 2026-10-27
Patch summary
This patch fixes an issue where the userfaultfd registration mode is not properly updated when changing from MISSING|WP to WP, leading to missing pages still waiting for userspace access. The problem arises because the current no-op check only compares the presence of specific flags and does not require exact mode matches. To fix this, the patch changes the comparison logic in userfaultfd_register_range() to ensure that the current and requested UFFD modes match exactly before skipping the update. This change is necessary to prevent writers from timing out due to missing faults.

Changing registration from MISSING|WP to WP returns success but leaves
MISSING enabled. The no-op check sees that WP is already set and skips
the update, so later accesses to missing pages still wait for userspace.

Skip the update only when the current and requested UFFD modes match
exactly.
