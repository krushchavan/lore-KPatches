Patch summary
This patch adds support for splitting PMD swap entries into 512 PTE swap entries in the Linux kernel's memory management (mm) module. This is done by adding a new branch to the __split_huge_pmd_locked() function that checks if the PMD entry is a swap entry and, if so, splits it into individual PTEs. The patch also updates the folio_remove_rmap_pmd() gate to correctly handle present THP splits. This change allows for more efficient handling of large pages in memory management scenarios involving swapping.
