[PATCH] mm: free the swap slot of a dirty swapin folio

View on lore.kernel.org →
Submitted: 2026-11-26
Active on: 2026-11-26
Patch summary
This patch optimizes Linux kernel memory management by freeing the swap slot of a dirty swapin folio when it's loaded from zswap, which reduces the cost of exit time and improves system performance. The patch addresses an issue where dirty folios left in the swap cache caused significant delays during exit, particularly on large production workloads. By releasing the swap cache at swapin, the patch eliminates this overhead and results in a 15% decrease in exit time on a production workload.
