[PATCH v2 2/2] mm/madvise: use vm_normal_folio_pmd() in cold/pageout PMD range

View on lore.kernel.org →
Submitted: 2026-09-12
Active on: 2026-09-12
Patch summary
This patch series addresses a bug in the madvise_cold_or_pageout_pte_range function, where it fails to validate the pfn on the way in when using vmf_insert_pfn_pmd(). The fix involves using vm_normal_folio_pmd() and skipping NULL folios, which also filters out huge zero PMDs. This patch specifically targets the cold/pageout PMD range.
