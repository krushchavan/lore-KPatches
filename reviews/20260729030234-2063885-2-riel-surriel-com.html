[PATCH 1/2] mm/gup: pass an end address to follow_page_mask() and return a page count

View on lore.kernel.org →
Submitted: 2026-07-29
Active on: 2026-07-29
Patch summary
This patch modifies the follow_page_mask() function in the mm/gup module to return a page count instead of a bitmask. The function is used to determine how many pages are covered by a returned page, and it now takes an additional 'end' argument to bound the search range. This change allows for more accurate handling of large folios and enables batching of PTE-mapped large folios in a later patch. No functional changes are intended by this patch.
