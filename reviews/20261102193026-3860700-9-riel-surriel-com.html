[PATCH 8/8] mm/gup: batch contiguous same-folio PTEs into one refcount grab

View on lore.kernel.org →
Submitted: 2026-11-02  ·  Last comment: 2026-11-03
Active on: 2026-11-03 • 2026-11-02
Patch summary
This patch optimizes the handling of large folios in the Linux kernel's memory management system by batching contiguous PTEs into a single refcount grab, reducing overhead and improving performance for certain workloads. The patch introduces a new function `gup_pte_batch_len` to determine how many PTEs can be batched together, and modifies the `gup_grab_folio_pages` function to use this information. This change is particularly beneficial for large folios (mTHP) and reduces the number of refcount grabs required, leading to significant performance improvements.
