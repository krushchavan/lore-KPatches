Patch summary
This patch adds a test to the selftests/mm suite to verify that the MADV_PAGEOUT functionality works correctly with file permissions. The test checks that an owner of a read-only file can evict a clean page, and that unauthorized callers cannot page out shared file pages or private mapping COW pages. The test also verifies that capabilities cannot be used as a substitute for ownership. The patch includes changes to the madvise.c file in the selftests/mm directory.
Sarthak Sharma 2026-10-16 Inline Review Reviewed-by Neutral LLM
Reviewer Sarthak Sharma noted that the map_temp_file function does not handle file permissions correctly when mapping a shared file, and suggested adding a mode parameter to specify the desired permissions. Reviewer Sarthak Sharma questioned the decision to pin to the current CPU only in one of three tests, suggesting that it should be applied consistently across all relevant tests. Reviewer Sarthak Sharma noted that the test case is flawed because it does not account for CPU migration, which can cause pages to be moved between CPUs and affect the LRU batch, potentially leading to incorrect results. The reviewer noted that if two CPUs are involved, lru_add_drain() on one CPU will prevent both pages from reaching the main LRU list, causing the test to skip prematurely. The reviewer suggested that instead of skipping the test if a CoW page cannot be swapped out, the patch should first check if pages can be skipped using pageout_until_swapped() and then fail the test if the CoW page was not skipped after retries.

   /* Ensure pageout-swap actually works first with a control page */
   control[0] = 1;
   if (!pageout_until_swapped(_metadata, control, page_size,
                              self->pagemap_fd))
      SKIP(return, "MADV_PAGEOUT did not swap the control page");

   /* Run the actual test */
   ASSERT_EQ(mapping[0], 0);  
   ASSERT_EQ(mapping[page_size], 0);
   mapping[0] = 1;

   ASSERT_TRUE(pageout_until_swapped(_metadata, mapping, 2 * page_size,
                                     self->pagemap_fd));
   ASSERT_TRUE(pagemap_is_populated(self->pagemap_fd,
                                    mapping + page_size));
   ASSERT_EQ(mapping[0], 1);         
   ASSERT_EQ(mapping[page_size], 0);
