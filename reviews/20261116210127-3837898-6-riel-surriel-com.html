Patch summary
This patch breaks out the gup_lookup_pte() helper from the larger follow_page_pte() function in mm/gup.c. The new helper resolves a present PTE to the page it maps, returning NULL if the PTE cannot be followed or a negative errno if the caller must report failure. This change simplifies the code and reduces complexity by separating the lookup process from the subsequent actions taken based on the result. No functional changes are intended as a result of this patch.
