Patch summary
This patch adds a new function called is_range_backed_by_order() to the Linux kernel's selftests/mm module. The function checks if a given address range is backed by folios of a specific order, ensuring that each part of the range maps one folio head-to-tail with its head at the start of the part. This is necessary for mTHP (memory Transparent Huge Pages) collapse tests to determine whether a collapsed range is distinct from an adjacent range. The function uses pagemap and kpageflags to verify the backing folios.
