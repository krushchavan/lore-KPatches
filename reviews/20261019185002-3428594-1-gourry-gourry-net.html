[PATCH] mm/vmscan: reclaim every zone in per-node proactive reclaim

View on lore.kernel.org →
Submitted: 2026-10-19  ·  Last comment: 2026-10-21
Active on: 2026-10-21 • 2026-10-20 • 2026-10-19
Patch summary
This patch modifies the per-node proactive reclaim function to scan every zone, not just ZONE_NORMAL, in order to reclaim movable memory as well. This addresses a problem where nodes with only movable memory were not being reclaimed properly. The approach taken is to change the `reclaim_idx` field of the `scan_control` structure to always set it to the maximum number of zones, allowing all zones to be scanned.
