Patch summary
This patch addresses a warning in the __mod_zone_page_state function, which is called when updating page statistics. The issue arises because this function requires preemption to be disabled, but it's being called on an offlined CPU where preemption isn't necessarily disabled. To fix this, the patch likely introduces local locks or similar synchronization mechanisms to ensure that per-CPU data access is properly synchronized.
Shakeel Butt (author) 2026-08-29 Needs Work LLM
Author acknowledged the need to disable preemption before calling stat update functions and suggested taking local locks like neighboring functions as a possible solution. Author identified the root cause of the issue as a missing lru lock acquisition in __munlock_folio, proposed a fix by adding local locks and reordering event counting, and plans to run tests before submitting a formal patch.
