[PATCH] nfsd: don't offer flexfiles layouts when NFSv3 isn't being served

View on lore.kernel.org →
Submitted: 2026-09-04
Active on: 2026-09-04
Patch summary
This patch prevents the flexfiles layout driver from being offered when NFSv3 is not enabled, fixing a bug where clients would loop on NULL calls and I/O would hang in D state.
Chuck Lever 2026-09-04 Positive LLM
Applied the patch to nfsd-testing and indicated that it can be dropped if a better solution is found.
