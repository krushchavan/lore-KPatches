Patch summary
This patch adds a new test, mthp_gup_cow_test, to the Linux kernel selftests suite. The test checks that the slow get_user_pages() path correctly handles large folios (mTHP) and copy-on-write (COW) operations. It does this by pinning a region of memory on the slow path, writing a distinct pattern to each page, and then verifying that the kernel copies back the correct contents from the pinned pages after a COW operation. The test also reports how many pages are in contiguous large-folio runs, allowing for better coverage testing of kernels without mTHP support.
★ Mike Rapoport 2026-07-26 Reviewed-by Neutral LLM
Reviewer noted that the test does not handle the case where the mTHP is split across multiple PTEs, which would cause the slow GUP path to return incorrect pages. Reviewer Mike Rapoport requested that the test code use ksft_* helpers for printing messages and tracking failed and passed tests, suggesting improvements to the test's logging and reporting functionality.
