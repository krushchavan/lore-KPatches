[PATCH 2/3] mm/swap: account synchronous swap reads as memory stall

Patch summary
This patch accounts for synchronous swap reads as memory stalls by modifying the folio_wait_bit_common function to trigger delay accounting and PSI (Pressure Stall Information) when a page is locked, not up-to-date, and in the working set.
Johannes Weiner (author) 2026-11-02 Positive LLM
Author explained their design choice to keep the write side in the same sequence, removing redundancy in swap_add_folio(), and confirmed it's easier for readers.
