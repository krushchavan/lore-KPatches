Patch summary
This patch series addresses four issues related to Transparent Huge Pages (THP) migration, swap-in, and device-private System Map (smaps). The patches fix a folio reference leak during THP splitting, prevent PTE batching from mapping hardware-poisoned pages, optimize smaps_pmd_entry() by reading the PMD only once, and correct the handling of non-present PMDs in smaps. Additionally, the series accounts for device-private PMDs using mapcounts in smaps, ensuring accurate Private Set Size (PSS) calculations.
