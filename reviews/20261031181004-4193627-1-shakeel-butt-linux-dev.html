[PATCH] vhost_task: do the return-to-userspace work between work items

View on lore.kernel.org →
Submitted: 2026-10-31
Active on: 2026-10-31
Patch summary
This patch modifies the behavior of vhost tasks, which are user worker threads that run kernel code only. It ensures that work that would normally be done on the way back to userspace, such as memory high reclaim and block cgroup throttling, is performed between work items in the vhost task loop. This is achieved by calling resume_user_mode_work() at the top of the loop if TIF_NOTIFY_RESUME is set, which allows for correct handling of these tasks without holding locks or waiting for signals. The patch addresses issues with memory high reclaim and block cgroup throttling not being handled correctly in vhost tasks, similar to those encountered in io_uring workers.
