[PATCH v1] mm/memcontrol: drop non-hierarchical memcg-wide stats in non-v1 kernels

View on lore.kernel.org →
Submitted: 2026-09-01
Active on: 2026-09-01
Patch summary
This patch optimizes the Linux kernel's memory control group (memcg) statistics by dropping non-hierarchical memcg-wide stats in kernels that don't support version 1 of memcg. This is done by compiling out the non-hierarchical arrays when CONFIG_MEMCG_V1=n, which reduces the number of cachelines pulled in during flush operations and makes them cheaper. The patch also includes benchmark results showing a 2-4% reduction in flush time on an 80-cpu x86_64 machine with 500 cgroups. The changes do not affect kernel builds with CONFIG_MEMCG_V1=y, which continue to support the legacy memory.stat and memory.numa_stat readers.
