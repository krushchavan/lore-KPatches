Patch summary
This patch declares the collapse interface in collapse.h, making it possible to use the functions from other files. The interface includes four main functions: collapse_control_init, collapse_scan_pmd, collapse_run_pmd, and collapse_control_release. These functions are used for collapsing memory pages and are part of a larger effort to implement MADV_COLLAPSE in madvise.c. The patch also renames hugepage_vma_revalidate to collapse_vma_revalidate and makes some minor changes to khugepaged.c.
David (Arm) 2026-09-23 Reviewed-by Neutral LLM
Reviewer David suggested replacing the current four functions (collapse_scan_pmd(), collapse_run_pmd(), etc.) with a single function called collapse_pmd() for cleaner code, but did not provide further details on how this would be implemented or what benefits it would bring. Reviewer David requested removal of collapse_control_release() as it is not intended to release any resources, unless a previous patch updated its behavior. Reviewer David (Arm) questioned the design of the collapse interface, specifically pointing out that collapse_vma_revalidate() is an odd part of it and suggesting the addition of a new function collapse_vma_validate() to perform initial validation on a given vma. Reviewer David requested kerneldoc comments for the newly declared interface in collapse.h, suggesting that similar documentation should be added to other functions exposed by the same interface.
