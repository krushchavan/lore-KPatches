Patch summary
This patch set separates the collapse engine from its callers, making it more modular and easier to understand. The caller specifies a policy that determines what actions are allowed, rather than relying on who called the function. This change is made by introducing new functions for scanning PTE tables and collapsing them, with the mmap_lock drop moved between these two operations. The patch set includes 9 patches in total, with some of them being standalone and others building upon each other.
Andrew Morton 2026-10-14 Inline Review Reviewed-by Needs Work LLM
Andrew Morton noted that the patch changes the function names from collapse_scan_anon_pmd and mthp_collapse to collapse_scan_anon and collapse_anon, but the callers in khugepaged.c still use the old function names. He requested that the callers be updated to match the new function names.
