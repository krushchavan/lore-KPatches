Patch summary
This patch removes the v1 soft limit feature from the Linux kernel's memory cgroup (memcg) implementation, which was deprecated in version 6.12 and has been replaced by v2 features such as memory.low and memory.min. The removal includes changes to various files, including memcontrol-v1.c, mm/vmscan.c, and include/linux/memcontrol.h, where the soft limit reclaim functionality is removed and related code is simplified or deleted.
