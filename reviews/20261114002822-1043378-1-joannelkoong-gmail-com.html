[PATCH v3 0/4] mm: read root memcg stats from global counters instead of flushing

Patch summary
This patch series modifies the Linux kernel to read memory cgroup (memcg) statistics from global counters instead of flushing them, which is expensive and can lead to stale stats. The root memcg's stats are updated directly from global counters, eliminating the need for flushing in most cases. However, three remaining flushes will be addressed in a subsequent patchset. This change improves performance by reducing the time it takes to read memcg statistics, especially on systems with many CPUs and active memory allocation.
