Patch summary
This patch series aims to improve the handling of memory allocation for Transparent Huge Pages (THP) in the Linux kernel. Specifically, it proposes a change to base the recommended minimum free kbytes on common memory nodes. This is done by adding a check to ensure that only zones on N_MEMORY_COMMON nodes are considered when reserving pageblocks for THP allocations.
Yury Norov 2026-11-22 Neutral LLM
Suggested refactoring the code to avoid duplicated checks and improve readability. Proposed a new macro for iterating over populated zones with specific node states.
