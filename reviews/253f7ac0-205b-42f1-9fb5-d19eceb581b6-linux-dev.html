[PATCH 3/5] mm/parisc: constify ptep_get() argument

Active on: 2026-07-24
Patch summary
The patch series aims to constify the argument of ptep_get() function, but Usama Arif's initial attempt in patch 1 fails to compile on certain architectures due to non-const function arguments.
Usama Arif 2026-07-24 Neutral LLM
Initially proposed constifying the argument of ptep_get() function, but acknowledged that it would break compilation on certain architectures. Agreed to squash the patches as a solution.
