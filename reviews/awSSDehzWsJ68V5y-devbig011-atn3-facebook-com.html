[PATCH v3] mm: add source selector to memory.reclaim

View on lore.kernel.org →
Submitted: 2026-11-23
Active on: 2026-11-23
Patch summary
The patch adds a source selector to memory.reclaim, enabling per-memcg-tier residency limits on machines running multiple workloads via memcgs.
Joshua Hahn 2026-11-23 Neutral LLM
Raised concerns about proactive reclaim not allowing swapouts, which could lead to pages having nowhere to go. Suggested starting a conversation about this point and how users should be expected to use the feature.
