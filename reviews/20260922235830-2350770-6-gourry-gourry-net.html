Patch summary
This patch refactors the handling of huge-PMD folios in the madvise code to separate the PMD lock and filtering logic from the rest of the function. It introduces a new helper function, madvise_lru_huge_pmd_locked, which is responsible for locking and referencing the folio when it must be split. The patch also moves some existing code into this new function, making the original function cleaner and easier to understand. No functional changes are intended by this refactoring.
