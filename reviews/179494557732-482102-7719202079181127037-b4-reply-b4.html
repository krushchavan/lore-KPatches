Active on: 2026-11-17
Patch summary
This patch fixes a bug in the Linux kernel's memory policy module where the function copy_nodes_to_user() would read and write one extra byte from/to user space when maxnode - 1 is a multiple of 32, leading to a stack over-read and leak. The fix involves converting maxnode to a bit count on entry to copy_nodes_to_user() and get_nodes(), ensuring that both the native and compat paths get the same size for the node mask. This patch addresses an issue introduced in commit e130242dc351 and is intended to be backported to stable kernels.
Arnd Bergmann 2026-11-17 Inline Review Reviewed-by Needs Work LLM
