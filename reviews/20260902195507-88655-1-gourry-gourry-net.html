[PATCH] mm/memory_hotplug: factor out node_is_memoryless()

View on lore.kernel.org →
Submitted: 2026-09-02
Active on: 2026-09-02
Patch summary
This patch refactors the memoryless node check in mm/memory_hotplug.c by extracting it into a separate function, node_is_memoryless(). The existing code is simplified and made more readable. No functional changes are introduced.
Gregory Price 2026-09-02 Needs Work LLM
Raised a concern about potential races between node_spanned_pages() and ZONE_DEVICE memory hotplug, suggesting that the issue may be worth revisiting in a separate patch.
