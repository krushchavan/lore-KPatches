Patch summary
This patch series fixes a bug in the deferred_split_isolate() function, which incorrectly handles frozen folios and leads to wrong results when !folio_try_get() is not caused by folio_put(). The bug was inert in upstream code but became apparent during review of another series. The patches fix deferred_split_isolate(), remove a workaround from __folio_freeze_and_split_unmapped(), and perform some cleanups in the same function. Testing has been done using various tests, including split_huge_page_test and folio_split_race_test.
