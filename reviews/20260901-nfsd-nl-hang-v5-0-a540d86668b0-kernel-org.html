Patch summary
This patch series hardens the netlink listener set interface in the NFS daemon and SunRPC code. It addresses issues such as incorrect error handling, listener registration problems, and potential hangs. The patches fix various bugs, including a case where a failed registration would leave behind orphaned entries in rpcbind. They also improve test coverage and add new tests to ensure correct behavior. The changes aim to make the netlink listener set interface more robust and reliable.
