Patch summary
This patch separates the scanning of a PTE table from its collapse into two distinct functions: `collapse_scan_pmd` and `collapse_run_pmd`. The scan function reads the table under the mmap_lock, while the run function performs the actual collapse. This change improves code organization and reduces the complexity of the original `collapse_single_pmd` function. Additionally, it allows for more efficient handling of file tables by khugepaged and introduces changes to tracing events.
