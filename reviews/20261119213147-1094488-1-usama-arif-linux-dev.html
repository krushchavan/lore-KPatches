Patch summary
This patch set improves the performance of stack poisoning in Linux by using a more efficient instruction (REP STOSQ) for large stack fills, reducing the time it takes to poison the task stack. This is particularly beneficial on systems with many small VMs, where the previous implementation was consuming around 1.5% of non-idle kernel cycles. Additionally, the patch includes a build fix for startup code that was causing issues when using Clang and certain configurations.

+static __always_inline void __stackleak_poison(unsigned long erase_low,
+					       unsigned long erase_high,
+					       unsigned long poison)
+{
+	unsigned long count = (erase_high - erase_low) / sizeof(unsigned long);
+
+	/* Amortize the startup cost of REP STOSQ. */
+	if (count < 32) {
+		unsigned long *ptr = (unsigned long *)erase_low;

+			case 0: ptr[--count] = poison; break;
