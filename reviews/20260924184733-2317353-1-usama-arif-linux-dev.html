David Laight 2026-09-24 Reviewed-by Needs Work LLM
Reviewer David Laight noted that the patch does not handle the case where key_len is a non-compile-time constant, and suggested using the ht->p path in this scenario. Reviewer David Laight questioned the optimization logic, pointing out that if ht->p.key_len/offset can differ from params.key_len/offset even when params is constant, then the specialization should only occur when the addresses of ht->p and params are compared in the calling code.
