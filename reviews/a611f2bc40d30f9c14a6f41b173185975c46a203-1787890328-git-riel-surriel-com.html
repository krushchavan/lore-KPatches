[PATCH] mm/memcontrol: avoid stuck FLUSHING_CACHED_CHARGE bit on isolated cpus

View on lore.kernel.org →
Submitted: 2026-08-28
Active on: 2026-08-28
Patch summary
This patch fixes a bug where the FLUSHING_CACHED_CHARGE bit can become stuck on isolated CPUs due to a race condition between the drain_all_stock() function and the schedule_drain_work() function. The patch reorganizes the drain_all_stock() loop, reducing nesting and splitting out local vs remote CPU handling, which solves the issue by skipping work on isolated CPUs. This fix is related to a previous commit that prevented draining charge PCP caches on remote isolated CPUs.
