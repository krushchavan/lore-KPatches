Patch summary
This patch adds selftests to cover kernfs dentry revalidation, which is crucial for maintaining the integrity of the kernel's file system cache. The tests simulate various scenarios where the kernel modifies kernfs nodes without VFS calls, and verify that the dentry cache is correctly updated. This includes checking how cached negative and positive dentries are dropped when files appear or disappear, as well as testing concurrent lookups and operations across removals. The patch also ensures that walking dentries already in the cache does not cause them to be dropped. The tests cover both filesystems (cgroup2 and sysfs) and confirm that they catch a broken backstop by stubbing kernfs_dir_changed() to return false.
