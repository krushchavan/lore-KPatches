Patch summary
This patch adds functionality to iterate over nodes that belong to a specific state, such as online or memory nodes. It introduces two new functions: first_node_state() and next_node_state(), which allow callers to walk through the nodes in a particular state. Additionally, it defines for_each_node_mask_state(), which intersects a nodemask with a node state using bitmap helpers without creating a temporary nodemask. This patch aims to simplify and improve the way node states are iterated over in the Linux kernel.
Gregory (Meta) 2026-11-20 Reviewed-by Neutral LLM
Reviewer noted that the implementation of for_each_node_mask_state() uses the bitmap intersection helpers, but this may not be efficient for large node masks or states, and requested a benchmark to verify its performance.
