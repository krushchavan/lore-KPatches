[PATCH 0/2] mm/gup: batch PTE-mapped large folios in follow_page_mask()

Active on: 2026-07-29
Patch summary
This patch improves the performance of large folio mapping by batching PTE-mapped large folios in follow_page_mask(). The current implementation walks one page at a time, even for contiguous mappings, which is inefficient. The patch introduces a new interface that returns the number of pages instead of a bitmask and allows batching consecutive present PTEs that map consecutive pages of the same folio. This results in significant performance improvements, with median get times reduced by 7.6x for 64 kB mTHP mappings.
